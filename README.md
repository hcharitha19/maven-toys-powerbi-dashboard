 Maven Toys Sales Dashboard (Power BI)

📌 Project Overview
This project analyzes sales performance of Maven Toys using Power BI.
The dashboard provides insights into revenue, profit, units sold, and monthly trends.

 📊 Dataset
The dataset includes:
- Sales table
- Products table
- Stores table
- Calendar table

 🛠 Tools & Skills Used
- Power BI Desktop
- Power Query (Data Cleaning)
- Data Modeling (Star Schema)
- DAX (Measures & Calculated Columns)

 🧱 Data Modeling
- Star schema design
- One-to-many relationships
- Custom Date Hierarchy (Month → Week → Date)
- Foreign keys hidden for report usability

 📈 Key Metrics
- Total Revenue
- Total Units Sold
- Total Cost
- Profit
- Monthly Trends of each metric

 🔍 Key Insights
- Revenue trends by month
- Top-performing products
- Store-wise performance comparison

📎 How to View the Project
1. Download the `.pbix` file
2. Open it using Power BI Desktop
